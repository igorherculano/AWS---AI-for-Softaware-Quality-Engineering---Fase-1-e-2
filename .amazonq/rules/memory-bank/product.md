# Product Overview

## Project Purpose
This is a learning portfolio repository for the **AWS & AI for Software Quality Engineering** scholarship program (Programa de Bolsas - PB). It consolidates all artifacts, test plans, automated test suites, and documentation produced across multiple sprints of the program.

## Value Proposition
Centralizes QA learning artifacts in a versioned, organized structure — covering manual testing, exploratory testing, API testing (Postman), and automated API testing (Robot Framework).

## Key Features & Capabilities

- **Manual & Exploratory Testing**: Bug reports (Jira screenshots), test plans (PDF), and exploratory test documentation
- **API Testing with Postman**: Exported collections and environments for ServeRest API
- **Automated API Testing with Robot Framework**: Full test suites covering Happy Path, Login, Users, Products, and Cart modules against the ServeRest API (`compassuol.serverest.dev`)
- **TDD with Python**: Calculator implementation using Test-Driven Development
- **Bug Tracking**: Documented bugs found during testing, linked to Jira tickets
- **Mind Maps**: Visual documentation of API concepts and use cases

## Target Users
Students and reviewers of the AWS & AI for Software Quality Engineering scholarship program.

## Use Cases
- Sprint deliverable reference and review
- QA automation portfolio demonstration
- Learning progression tracking across Fase 1 (Sprints 2–6) and Fase 2 (Sprints 1–2)
